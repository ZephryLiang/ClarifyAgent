# Google XYZ 公式（成果量化模板）

## 核心公式
> **Accomplished [X] as measured by [Y], by doing [Z].**
> 达成了 **[X 成果]**，其量化指标为 **[Y 数据]**，通过 **[Z 做法/技术]** 实现。

也常写作：**"通过 Z，实现了 Y 衡量的 X"**。

## 为什么有效
- 强制把「做了什么」升级为「带来了什么可衡量的结果」。
- X（成果）+ Y（量化）+ Z（方法）三要素齐全，招聘者一眼看到影响力与能力。
- 避免只罗列职责（responsibilities），转而突出成就（accomplishments）。

## 改写示例
- 反例（只有职责）：负责后端接口开发和性能优化。
- 正例（XYZ）：将订单查询接口 P99 延迟从 800ms 降低到 220ms（Y），支撑大促期间 15k QPS（X），通过引入 Redis 多级缓存与 SQL 索引重构（Z）。

## 使用注意（反幻觉）
- Y 的数字必须来自候选人**真实**提供的数据；若缺失，用占位符 `[待补充: 具体指标]`，**不得编造**。
- Z 只能写候选人实际使用过的技术/方法。

## 出处 / Sources
- Laszlo Bock（Google 前人力资源高级副总裁），*Work Rules!*（2015）中提出该表达范式。
- Google Careers 简历指南长期引用「Accomplished X as measured by Y, by doing Z」。
