# 强动词开头（Action Verbs）

## 原则
每条简历经历以**强动词**开头，避免「负责/参与/协助」这类弱表达；用主动、具体、结果导向的动词。

## 推荐动词分类
- **主导/领导**：主导、牵头、设计、架构、推动、Led、Spearheaded、Drove、Architected。
- **构建/交付**：构建、实现、开发、交付、上线、Built、Implemented、Shipped、Launched、Delivered。
- **优化/提升**：优化、重构、提升、降低、加速、Optimized、Refactored、Improved、Reduced、Accelerated。
- **分析/解决**：分析、定位、诊断、解决、Analyzed、Diagnosed、Resolved、Debugged。
- **协作/影响**：协调、对齐、推动跨团队、Coordinated、Aligned、Influenced、Mentored。

## 弱→强 改写
- 弱：负责数据同步模块的维护。
- 强：重构数据同步模块，将失败重试成功率从 92% 提升至 99.9%。

- 弱：参与了推荐系统项目。
- 强：设计并实现推荐系统的召回链路，覆盖 500 万日活用户。

## 反幻觉约束
- 动词升级不得夸大真实角色：只是「参与」的，不要写成「主导」。

## 出处 / Sources
- MIT / Harvard / Berkeley 等高校 Career Center 简历指南普遍提供 action verb 列表并要求动词开头。
