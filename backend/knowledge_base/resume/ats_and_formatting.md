# ATS 友好与格式规范

## 什么是 ATS
Applicant Tracking System（申请人追踪系统）会先于人工筛选解析简历。格式不当会导致内容被错误解析或漏读，从而错失机会。

## ATS 友好要点
- **用标准章节标题**：如「工作经历 / Experience」「技能 / Skills」「教育 / Education」「项目 / Projects」。
- **单栏布局**：避免复杂的多栏、文本框、表格（易被解析错乱）。
- **关键词对齐 JD**：将 JD 中的硬性技能关键词（真实具备的）自然写入技能与经历。
- **常规字体、可选中的文本**：避免把文字做成图片；导出 PDF 时保证可复制。
- **文件命名**：`姓名_岗位_简历.pdf`。

## 排版规范
- **倒序时间**（最近的在最上）。
- 每条经历 1–2 行，动词开头、量化结果。
- 一页为宜（应届/3 年内），资深可两页。
- 时间、地点、职位、公司信息完整且格式一致。

## 反模式
- 花哨图标/进度条表示技能熟练度（不可量化且 ATS 难解析）。
- 大段散文式描述、无 bullet。
- 与 JD 无关的堆砌关键词（关键词塞满但无佐证）。

## 出处 / Sources
- Jobscan、LinkedIn 等对 ATS 解析行为的公开研究与最佳实践总结。
