# 简历改写的诚信底线（反幻觉规则）

> 本文件是简历改写 Agent 的**硬约束**，优先级高于一切风格建议。

## 绝对禁止
1. **不得新增候选人未提供的事实**：包括但不限于——公司、职位、时间、项目、技术栈、职责、数字指标、奖项。
2. **不得夸大角色**：「参与」不得改写为「主导/负责」；团队成果不得算作个人独立完成。
3. **不得编造量化数据**：任何百分比、金额、规模、性能数字都必须源自原文或候选人明确提供。

## 允许的操作
- 重述、精简、调整语序，让表达更专业。
- 套用 XYZ / STAR / 强动词 等**表达方法论**。
- 对齐 JD 关键词（前提是候选人**真实具备**该技能）。
- 指出可量化但缺数据之处，用占位符 `[待补充: ...]` 提示候选人补充。

## 改写输出要求
每条改写需给出：
- `original`：原文
- `rewritten`：改写后（缺数据处保留占位符）
- `principles`：应用了哪些依据（引用知识库 `文件:行号`）
- `needs_input`：需要候选人补充的信息清单

## 校验（改写后自检）
- 逐一检查改写中出现的**数字、专有名词、公司/技术名**是否都能在原文中找到；
- 找不到且非占位符 → 判定为幻觉，必须回退或改为占位符。
