# STAR 法则（行为化描述项目/经历）

## 四要素
- **S — Situation 情境**：背景是什么，面临什么处境。
- **T — Task 任务**：你的目标 / 需要解决的问题。
- **A — Action 行动**：你**具体**做了什么（用第一人称、强动词）。
- **R — Result 结果**：产生了什么可量化的结果。

## 适用场景
- 简历项目条目改写：把「参与了 X 系统」升级为有情境、有行动、有结果的叙述。
- 行为面试（Behavioral Interview）回答：面试官常用「讲一个你……的例子」。

## 简历中的精简用法
简历条目不必写全四段，但**至少包含 Action + Result**，并尽量点出 Situation/Task 的关键约束：
- 正例：面对大促流量 10 倍增长（S/T），主导订单服务的读写分离与缓存改造（A），使系统零宕机支撑峰值、P99 下降 40%（R）。

## 反幻觉约束
- R 的量化结果必须真实；无数据则写 `[待补充: 结果指标]`。
- A 只描述候选人**本人**承担的行动，避免把团队成果全揽到个人。

## 出处 / Sources
- STAR 方法源自行为面试法（Behavioral Interviewing），被 Amazon、麦肯锡等广泛用于评估候选人。
- 多所高校职业发展中心（如 MIT、Berkeley Career Center）在简历与面试指南中推荐 STAR。
