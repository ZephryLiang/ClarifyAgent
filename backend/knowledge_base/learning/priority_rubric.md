# Learning plan priority rubric

Use when assigning `effective_tier` to requirement matrix rows and when applying natural-language revisions.

## Tier definitions

| Tier | Label | When to use |
|------|-------|-------------|
| P0 | Must learn now | Appears in ≥2 JDs as hard requirement; user explicitly prioritizes; blocks interview talking points |
| P1 | High value | Required in one JD + strongly related to resume gaps |
| P2 | Nice to have | Preferred skill or adjacent technology |
| P3 | Defer | Rare mention; user asked to defer; low ROI within time budget |

## Revision triggers (natural language)

- **Promote to P0**: 最重要, 优先, 先学, p0, 提前, 这周就要
- **Defer to P3**: 不要, 删掉, defer, 暂缓, 以后再说
- **Extend time**: N 周, N 小时/周 — update workspace `time_budget` then regenerate plan

## Phase allocation

- Allocate ~60% of hours to P0, ~30% to P1, remainder to P2
- Each week should have one concrete deliverable (project milestone, mock interview topic, or written summary)
