# Role taxonomy

Offline labels used by `RoleAssessor` when LLM is unavailable or as baseline.

## Types

| id | label | Keywords in JD |
|----|-------|----------------|
| agent_runtime | Agent Infrastructure / Runtime | agent, runtime, checkpoint, durable, orchestration, LLM infra |
| backend_platform | Backend Platform | platform, infra, middleware, SDK, developer tools |
| ml_engineering | ML Engineering | training, inference, model serving, feature store |
| backend_general | Backend General | API, microservice, CRUD, business logic (default) |

## Assessment dimensions

- **learning**: high / medium / low — depth of transferable skills
- **market_demand**: rising / stable / niche
- **ceiling**: senior+ / staff / limited

## Tradeoffs to surface

- Depth vs business visibility
- Greenfield vs maintenance-heavy legacy
- Big-tech brand vs startup equity upside
